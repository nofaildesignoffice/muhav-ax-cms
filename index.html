01 탐색
이 단계가 하는 일무하브에 맞는 나노 인플루언서 후보를 데이터 업체(피처링)와 X 공식 API에서 조건 검색으로 모아 오는 단계입니다.
지금 업무에서 해결하는 것지금은 대표님과 알바가 인스타·X를 직접 뒤져 시트에 계정마다 13개 항목을 손으로 입력합니다(누적 1,633건, 대표님 서칭은 회당 1시간 이상). 조건 검색으로 후보를 자동으로 모으고, 이미 컨택했거나 거절한 계정은 자동으로 걸러냅니다.
01 탐색높음
  • 인스타 탐색: 가능. 피처링·HypeAuditor·Modash 같은 데이터 벤더가 카테고리·팔로워 구간·국가·참여율 조건 검색과 유사 계정 추천을 제공 (벤더가 자체 수집·제휴로 DB 구축)
  • 인스타 공식 경로: Meta Creator Marketplace·Creator Discovery API (JP·KR 필터, 마켓플레이스 가입 크리에이터 한정, Advanced Access 필요)
  • X 탐색: X API v2 일본어 키워드 검색 (종량제, 게시물 조회 $0.005). 피처링·HypeAuditor도 X 지원
  • Business Discovery: 아이디를 아는 프로 계정 지표 보강
  • 무하브가 직접 만들 경우: Meta 공식 API에는 조건 검색 기능이 없음 → 벤더 DB를 쓰는 이유
  • 해시태그 API는 작성자 아이디를 주지 않고 24시간 이내 게시물만 반환 → 탐색용 부적합

  • 벤더의 일본 나노 커버리지는 미검증 → PoC 필요

02 점수화
이 단계가 하는 일모은 후보마다 무하브와 맞는지(민감성·임산부·K뷰티 리뷰 등)와 수락 가능성을 AI가 점수와 근거로 매기는 단계입니다.
지금 업무에서 해결하는 것지금은 선정 기준이 담당자 판단과 시트 비고란에 흩어져 사람마다 다릅니다. 실측상 나노 계정 수락률은 33%인데 매크로는 0~5%라는 차이도 선정에 반영되지 않았습니다. 데이터에 근거한 점수가 나오면 대표님은 추천 목록을 승인만 하면 됩니다.

  • 가짜 팔로워를 "확정"할 수는 없음 → 위험도 등급으로 표시

03 컨택
이 단계가 하는 일승인된 후보에게 유형별 맞춤 DM 문안(한국어·일본어)을 자동으로 만들고, 사람이 원클릭으로 보내는 단계입니다.

1. 처리량 회복 실측 전환율

  • 월 컨택이 6월 540건에서 8~9월 약 140건으로 줄었습니다 (−75%)

2. 누락 회수 일부 가정

  • 회신 대기 817건을 90일 이내·거절 없음 기준으로 1회 리마인드 → 10%만 수락해도 업로드 약 39건 추가 (일회성)
  • 업로드 확인 139건, 송장 71건, 깨진 송장 약 30건 → 0건
  • 수락 대비 업로드율 48% → 60% 목표 (배송완료 시점에 맞춘 리마인드)

3. 매출 귀속 데이터 현재 0%

  • 인플루언서별 확정 매출: 전용 쿠폰·SKU·공구 기준
  • 광고 활용 동의 입력률 0% → 배송 폼에서 수락자 100% 수집
  • "어떤 계정이 매출을 만드는가"가 처음으로 숫자가 되고, 이것이 탐색 기준을 다시 학습시킵니다

  • 담당자가 바뀌어도 대화·판단 근거가 DB에 남음
