  • 업로드 확률 예측: 컨택 약 1,500건 기준으로 특징 15개 이하의 단순 회귀 모델
  • 업로드 500건 이후: 더 정교한 머신러닝 모델을 보조로 추가

"공통점"으로 인정하는 기준

  • 컨택 30건, 업로드 8건 이상인 묶음만 리포트에 올림. 미달은 "관찰 중"
  • 효과가 있을 확률 90% 이상, 평균보다 20% 이상 높고, 직전 기간에도 같은 방향일 때만 채택
  • 업로드한 사람만이 아니라 컨택한 전체를 분모로 계산
  • 컨택 전에 알 수 있는 정보만 탐색 점수에 사용. DM 반응은 수락 후 업로드 예측에만 사용
  • 일본 X가 업로드의 87%라 플랫폼별로 분리해 분석

4. 점수화와 탐색에 어떻게 반영하나

점수 반영

  • 우선순위 = 브랜드 핏 통과 × 업로드 확률 × 기대 성과 점수 + 탐색 보너스. 브랜드 핏은 학습하지 않는 기준선
  • 월 1회 재학습 → 새 기준으로 대기 목록을 미리 채점 → 순위가 어떻게, 왜 바뀌는지 확인 → 대표님 승인 후 적용
  • 예측 정확도가 떨어지면 자동 적용 금지. 적용 후 2주 안에 업로드율이 나빠지면 이전 버전으로 되돌림. 모든 점수에 버전 기록

탐색 반영과 효과 검증

  • 컨택 배분: 70% 상위 점수 · 15% 인접 유망 묶음 · 10% 무작위 탐색 · 5% 비교군(기존 방식)
  • 탐색 조건 갱신: 채택된 공통점을 피처링 검색 필터 프리셋, X 검색 키워드, 유사 계정 시드(성과 상위 20명)로 반영
  • 검증: 3개월 누적으로 상위 점수 그룹과 비교군의 업로드율을 비교하고, 예측 확률과 실제 결과가 맞는지 점검
  • DM 템플릿: 두 가지 문안을 무작위로 나눠 보내 어떤 문안이 수락률이 높은지 확인
